CLI options

daemonitor-cli is a native Go thin client for daemonitor-cored, the native core that owns process data and the shared database. An installed package includes the sibling core; the CLI starts it automatically when needed. It does not require Java or a JDK. 

brew tap cdsap/tap
brew install daemonitor-cli
daemonitor-cli --help

Also available as daemonitor-cli-*.zip on GitHub Releases (no JDK required).

Commands

Command What it does
daemonitor-cli Open the interactive monitor on a TTY; otherwise print one process snapshot.
daemonitor-cli top Open the interactive monitor. Requires a TTY.
daemonitor-cli ps Print one process snapshot and exit. Supports PID/project filters and watch mode.
daemonitor-cli history Print process history with a configurable time window and row limit.
daemonitor-cli builds Print recent builds.
daemonitor-cli logs [pid] List daemon logs, or show a retained log tail for one daemon.
daemonitor-cli health Show core health and connection information.

Options

Option What it does
--socket PATH Use an explicit daemonitor-cored Unix socket.
--poll-interval DURATION Set the interactive monitor refresh interval. Default: 2s.
--no-color Disable color. The NO_COLOR environment variable does the same.
--no-autostart Do not start the sibling daemonitor-cored automatically.
--json Emit machine-readable JSON where supported by one-shot commands.
--format plain|json|jsonl|csv Select human-readable, JSON, JSON Lines, or row-oriented CSV output.
--since DURATION Set the history window, for example 1h or 15m.
--limit N Limit returned history or build rows.
--pid PID / --project TEXT / --status TEXT Filter process, log, project, or build results.
--watch --until DURATION Continuously refresh ps output, optionally stopping after a bounded duration.
--fail-on-rss MB In watch mode, print the triggering snapshot and exit with code 3 when RSS reaches the threshold.
--help Print usage and exit.
--version Print the CLI version and exit.

Everyday usage

daemonitor-cli
daemonitor-cli ps --json
daemonitor-cli builds --status FAILED --format csv
daemonitor-cli history --since 1h --project daemonitor --format jsonl
daemonitor-cli ps --watch --poll-interval 5s --until 1m
  • Press q to quit the interactive monitor.
  • Over SSH, allocate a TTY: ssh -t host daemonitor-cli.
  • Redirected or non-interactive sessions should use a one-shot command such as daemonitor-cli ps --json.
  • Use daemonitor-cli top for an explicit interactive monitor, or daemonitor-cli health to inspect the core connection.
  • Press enter on a process to see recent build/log context and its RSS trend.

Interactive monitor

Run daemonitor-cli in a TTY to open the full-screen monitor. It refreshes every two seconds by default and keeps the terminal in the monitor until you quit.

Press v to group descendant workers below their daemon. The group row aggregates descendant resource use while the tree keeps each process visible; use h/l to fold or expand the selected group, or E/C to expand or collapse all groups.

Interactive monitor key bindings
Key Action
↑/↓ or j/k Select a process and scroll through the process rows. g and G jump to the first and last row.
v Toggle flat rows and grouped process hierarchy. Group rows aggregate descendants and retain their child rows.
h/l, E/C Collapse or expand the selected group, or collapse/expand every group.
s Cycle the sort column: RSS, CPU, PID, type, uptime, project, heap used, heap committed, and Xmx.
S Toggle ascending or descending sort order.
space Pause or resume automatic refresh. Press r for an immediate refresh, including while paused.
enter Open details for the selected process, including its retained daemon-log tail when available.
x / X Kill the selected process, or every listed process. Press y to confirm; any other key cancels. Processes receive a termination signal (SIGTERM on macOS and Linux).
esc Close process details and return to the table. ? toggles the in-app key-help line.
q or Ctrl+C Quit and restore the terminal. The monitor adapts its columns after a resize; very narrow or short windows ask you to enlarge the terminal.

The TUI requires a terminal. For redirected output, scripts, or JSON consumers, use daemonitor-cli ps --json or --format jsonl; daemonitor-cli top is intentionally TTY-only.
