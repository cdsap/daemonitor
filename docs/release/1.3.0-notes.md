# Daemonitor 1.3.0 — draft release notes

Use this body (or a trimmed copy) when creating the `v1.3.0` GitHub Release after
the prep PR merges and CI is green.

## Highlights

- **Bazel as a peer of Gradle** — live observation of Bazel servers, tests, and
  workers from argv (zero-lock: never calls `bazel info` / `dump`).
- **TUI hierarchy** — Bazel servers are hierarchy roots alongside Gradle daemons;
  fold/expand workers under the server.
- **Desktop Live + History** — Bazel labels and detail titles; History tool filter
  (Gradle / Bazel); Bazel detail for BEP rows.
- **Opportunistic BEP history** — when a build already writes local BEP, retained
  rows appear in History and under Bazel server details. Daemonitor never enables
  BEP itself.
- **Docs / site** — README and GitHub Pages treat Gradle and Bazel with equal
  weight; CLI docs shot is the main process table.

## Gradle plugin

- Artifact `io.github.cdsap.daemonitor` remains **0.1.0** (no plugin API change in
  this cut).
- Portal publish still needs `GRADLE_PUBLISH_KEY` / `GRADLE_PUBLISH_SECRET` on the
  repo. Without them, `release.yml` soft-skips Portal publish so native assets
  still ship. Backfill via Actions → **Publish Gradle plugin** → ref `v1.3.0`.

## Install

Desktop and CLI packages: GitHub Releases `v1.3.0`.

```bash
brew tap cdsap/tap
brew install daemonitor-cli
```
