# Daemonitor 1.3.2 — Observation session depth + plugin docs

Ships the observation-session enrichment from #560 and bumps the Gradle plugin
for Plugin Portal republish with clearer “why this plugin” documentation.

## Product (1.3.2)

Observation close summaries now include:

- `process_type` (`GRADLE_DAEMON`, `KOTLIN_DAEMON`, …)
- Build-window sample timestamps (`first_sample_at_ms` / `last_sample_at_ms`)
- Heap / metaspace / young–old GC first → peak → last → delta when HotSpot
  samples exist

Desktop, CLI, and `daemonitor-cored` packages: GitHub Releases `v1.3.2`.

## Gradle plugin (0.1.1)

- Settings plugin: apply in `settings.gradle.kts` (`Plugin<Settings>`)
- Close-summary fields for local report / GBOS / Develocity projection
- Portal description and website point at the “why plugin” docs
- Docs: `gradle-plugin/README.md`, root README, site `#gradle-plugin`

```kotlin
// settings.gradle.kts
plugins {
    id("io.github.cdsap.daemonitor") version "0.1.1"
}
```


## Install

```bash
brew tap cdsap/tap
```
