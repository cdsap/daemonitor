# Daemonitor 1.3.2 — Observation depth + Gradle plugin first publish

Ships observation-session enrichment from #560 and the first Plugin Portal
publish of `io.github.cdsap.daemonitor` **0.1.1** (Settings plugin + Develocity
GBOS custom values).

## Product (1.3.2)

Observation close summaries now include:

- `process_type` (`GRADLE_DAEMON`, `KOTLIN_DAEMON`, …)
- Build-window sample timestamps (`first_sample_at_ms` / `last_sample_at_ms`)
- Heap / metaspace / young–old GC first → peak → last → delta when HotSpot
  samples exist

Desktop, CLI, and `daemonitor-cored` packages: GitHub Releases `v1.3.2`.

## Gradle plugin (0.1.1)

First Portal publish. Apply in `settings.gradle.kts` only:

```kotlin
// settings.gradle.kts
plugins {
    id("io.github.cdsap.daemonitor") version "0.1.1"
}
```

Included in this cut:

- Settings plugin (`Plugin<Settings>`) — #562
- Develocity `buildFinished(Action)` overload (not Groovy `Closure`) so `gbos.*`
  custom values publish — #563
- Reuse the captured observation BuildService for Develocity close (avoids empty
  session B / empty `processes` overwrite) — #564
- Local report / GBOS projection of close-summary fields
- Portal description and website point at the “why plugin” docs

## Install

```bash
brew tap cdsap/tap
brew install daemonitor-cli
```

Desktop packages: GitHub Releases `v1.3.2`.
