# Daemonitor 1.3.3 — Deep Bazel observation, Kotlin Toolchain CLI, and telemetry/UI polish

Ships passive Bazel `<output_base>` and rich BEP observation, `KOTLIN_TOOLCHAIN`
process classification, pure-Go macOS `proc_pid_rusage` telemetry, JVM probe
cadence/heap/storage fixes, and Desktop + CLI polish. Also cuts Gradle plugin
`io.github.cdsap.daemonitor` **0.1.2**.

## Product (1.3.3)

### Bazel observation depth
- Zero-config build metrics and history from passive `<output_base>` watching
  (`server/jvm.out`, `command.log`, `command.profile.gz`) — #588, #593
- Rich BEP `BuildMetrics` and length-delimited binary BEP
  (`--build_event_binary_file`) decoding with opt-in API/MCP details surface — #598, #604
- Sandbox ancestry bridging and subtree RSS aggregation (#591), live heap probing
  gated to JVM-backed `BAZEL_WORKER` / `BAZEL_TEST` processes (#592), and
  coding-agent attribution via client ancestry and BEP env vars (#599)
- Build-window process sample correlation, heap/GC deltas, and retention — #601
- TUI and Desktop Bazel server detail parity — #597 / #610

### Kotlin Toolchain CLI
- Classify ephemeral Amper `MainKt` JVMs launched by `kotlin build|test|run` as
  `KOTLIN_TOOLCHAIN` without conflating them with Gradle `KotlinCompileDaemon` — #603

### JVM & OS telemetry reliability
- Collect macOS `proc_pid_rusage` CPU and disk I/O metrics via `purego` with
  `CGO_ENABLED=0` — #637 / #643
- Independent JVM probe cadences isolated from OS polling (#615), preserved
  original measurement timestamps on cached probes (#612), persisted live JVM
  counters in process history (#613), and effective JVM `-XX` flags metadata (#614)
- Parse `jcmd GC.heap_info` reserved heap bounds into `heap_max_mb` across G1GC,
  ParallelGC, and SerialGC (#622 / #629, #639 / #644), fix `CodeCache` max/committed
  mapping (#628), and handle blank `FailedMethod` in `jstat -compiler` (#611)

### Storage, CLI, and Desktop polish
- Deduplicate `process_samples` command lines into `process_command_lines` to avoid
  repeating full command lines every 2 s (#638 / #646, #649) and release ThreadLocal
  SQLite connections cleanly on Windows (#649)
- `daemonitor-cli logs`: honor `--limit`, label Bazel logs cleanly, and sort
  deterministically with active daemons and newest files first — #624 / #633, #634,
  #640 / #648, #650
- `daemonitor-cli export`: reject unsupported `--format` values (#641 / #645); return
  most recent history samples filtered by `pid` / `start_time_ms` (#619 / #626)
- Desktop UI polish at 1180×760+: responsive Live table columns, 5-tab detail pane
  layout, `working_directory` PROJECT fallback, LogCard layout/empty state, Visual
  horizontal scrollbars, and History `STARTED` column / pills / UUID header /
  `DetailRow` ellipsis — #618 / #627, #620 / #631, #621 / #632, #625 / #635 / #636,
  #630, #642 / #647

Desktop, CLI, and `daemonitor-cored` packages: GitHub Releases `v1.3.3`.
